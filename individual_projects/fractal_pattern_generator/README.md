# Fractal Pattern Generator
***
![Image of running project](relative to image in my repository)
This project will take a recursion depth betweeen 1 and 5, a color, and then generate a Sierpinski Triangle based on the recursion depth.

## How to use the Project
***
1. Run main file
2. Enter recursion depth (1-5)
3. Enter any valid color
4. Program will then generate a Sierpinski Triangle
5. Pressing enter in terminal will close

## Key Features
***
- Choose a recursion (1,5)
- 33 Colors to choose from
